# Elion Blanc — sitio web

Ecosistemas web inmersivos para negocios en Lima. Sitio estático hecho con Vite (HTML, CSS y JS sin frameworks).

## Desarrollo
```
npm install
npm run dev
```

## Producción
```
npm run build   # genera dist/
```
Se despliega en Vercel (framework: Vite, salida: `dist`). Dominio: elionblanc.com
